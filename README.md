# ChromaVision — Accessible Dashboard for Colorblind Users

## See Data Beyond Colors

ChromaVision is a modern accessibility-focused data visualization dashboard specially designed to improve chart readability for colorblind and visually impaired users.

Traditional dashboards often rely only on colors to represent data, making charts difficult to understand for users with Color Vision Deficiency (CVD). ChromaVision solves this problem using accessible color palettes, high-contrast visualization, pattern-based differentiation, and WCAG-inspired design principles.

This project combines accessibility, responsive UI/UX, interactive analytics, and modern frontend engineering into one platform.

---

# Why This Project?

Millions of users around the world experience some form of colorblindness or low vision.

Most dashboards:
- Depend heavily on color
- Ignore accessibility
- Become difficult to interpret for CVD users

ChromaVision was created to make data visualization:
- Accessible
- Inclusive
- Readable
- User-friendly
- Colorblind-safe
